# Code of conduct

Treat contributors and users with respect. Give specific, constructive feedback,
welcome different experience levels, and keep discussions focused on the project.

Harassment, discriminatory language, threats, publishing private information,
and repeated disruptive behavior are not acceptable in issues, pull requests,
or other project spaces.

Maintainers may edit or remove inappropriate content and restrict participation
to keep these spaces useful and safe. They should explain moderation decisions
when doing so does not expose private information.

Use GitHub's report-content tools for abusive content. For concerns that require
a private conversation, ask a maintainer for a private reporting channel without
posting names or sensitive details publicly. Security vulnerabilities follow
the separate [security reporting instructions](.github/SECURITY.md).
